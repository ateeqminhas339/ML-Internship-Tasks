# Task 05 — Regression Modeling: From Scratch to Production

Predicts medical insurance `charges` on the [Medical Cost Personal](https://www.kaggle.com/datasets/mirichoi0218/insurance)
dataset (same dataset as Task 04) — implemented **from scratch** (plain NumPy gradient
descent) and **in production form** (a scikit-learn pipeline, served via FastAPI,
containerized with Docker).

## What this task does

- Implements multiple linear regression **from scratch** with batch gradient descent
  (`src/modeling.LinearRegressionFromScratch`) and confirms it matches sklearn's
  closed-form `LinearRegression` (R² ≈ 0.887 vs. 0.886)
- Engineers a `smoker_bmi_interaction` feature (a well-documented driver of charges)
- Compares 4 production candidate models (Linear Regression, Ridge, Random Forest,
  Gradient Boosting) through an identical preprocessing pipeline
- Selects the best model (**GradientBoostingRegressor**, R² ≈ 0.901) and serializes it
- Serves the model through a **FastAPI** app (`api/app.py`) with `/predict` and `/health` endpoints
- **Containerizes the API with Docker** (`Dockerfile` + `.dockerignore`)

## How to run the notebook

```bash
pip install -r requirements.txt
jupyter notebook notebook.ipynb
```
Run all cells top-to-bottom. This regenerates `figures/` and `api/model.joblib`.

## How to run the API locally (no Docker)

```bash
pip install -r api/requirements.txt
uvicorn api.app:app --reload
```
Then visit `http://localhost:8000/docs` for the interactive API docs, or:
```bash
curl -X POST http://localhost:8000/predict -H "Content-Type: application/json" \
  -d '{"age":35,"sex":"male","bmi":28.5,"children":2,"smoker":"no","region":"southeast"}'
```

## How to run with Docker

```bash
docker build -t insurance-charges-api .
docker run -p 8000:8000 -p 8501:8501 insurance-charges-api
```
This starts both:
- the FastAPI JSON API at `http://localhost:8000` (same `curl` command above works, plus interactive docs at `/docs`)
- a Streamlit browser UI at `http://localhost:8501` for predicting charges through a form
